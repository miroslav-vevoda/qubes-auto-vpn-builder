# tools/rpm/manifest.txt
#
# THE reviewed list of what may end up in dom0. Two things read this file:
#
#   build-rpm.sh    generates the spec's %files section from it
#   vpn-rpm-audit   checks the BUILT package against it
#
# They are deliberately separate directions. build-rpm.sh says what the
# package should contain; vpn-rpm-audit asks the finished .rpm what it
# actually contains and compares. A build that goes wrong -- or a spec edited
# behind your back -- shows up as a mismatch rather than as agreement.
#
# So this file is the thing to review. If a path is not listed here, it does
# not get installed, and the audit fails if the package carries it anyway.
#
# Format:  <mode> <path relative to dom0/> [flags]
#
#   mode    octal, four digits
#   path    also the install path, with a leading "/" added
#   flags   optional, comma-separated:
#             config   -- %config(noreplace); user may edit, upgrades keep
#                         their version rather than overwriting it
#             dir      -- own the directory itself, not a file
#
# Nothing here may be setuid, setgid, world-writable, a symlink or a device.
# vpn-rpm-audit enforces that against the package regardless of what this
# file says, so a bad edit here cannot quietly widen what ships.
